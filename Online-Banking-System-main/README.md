# Online Banking Management System

A modern Online Banking System built using HTML, CSS, JavaScript and Java.

## Features

* User Registration & Login
* Dashboard Analytics
* Deposit & Withdraw Money
* Transfer Money with OTP Verification
* Transaction History
* Search Transactions
* Dark Mode
* AI Banking Assistant
* Budget Tracking
* Notifications System
* Animated Banking Card
* Profile Management
* Responsive Design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Java
* Local Storage
